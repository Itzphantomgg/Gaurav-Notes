# Temp Notes - Principles of Management (PM)

A clean, minimalist web app to study and refer to **Principles of Management** notes.

🔗 **Live Website**: [https://itzphantomgg.github.io/Gaurav-Notes/](https://itzphantomgg.github.io/Gaurav-Notes/)

---

## ✨ Features

- **No Clutter, Zero Emojis**: Clean, modern typography and clean SVG vector icons.
- **Principles of Management (PM)**: Dedicated subject reference.
- **In-Browser Question Editor (Pencil Icon)**: Click the pencil icon on any question or the "+ Add Question" button to write and save notes directly in the browser.
- **Student Profile**: Customize the student or friend's name right on the sidebar.
- **Animated Scroll**: Fluid scrolling and slide animations when browsing questions.
- **Direct Question Sharing**: Every question has a direct URL hash (`#q1`, `#q2`, etc.).
- **Search & Filter**: Real-time search across questions, categories, and content.
- **Export to Code**: Export notes to `questions.js` with one click to permanently push to GitHub.
- **Dark / Light Theme**: Clean distraction-free reading modes.
