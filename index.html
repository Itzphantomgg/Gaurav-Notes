How to Add or Edit Your Notes

Your notes are stored in questions.js. You can easily add as many questions as you like with full Markdown, code blocks, lists, and tables.

Option 1: Edit questions.js directly (Recommended)

Open questions.js in any editor and add new entries to the questions array:

{
  id: 3,
  badge: "Q.3",
  title: "Explain the difference between TCP and UDP?",
  category: "Networking",
  tag: "Important",
  answer: `### TCP vs UDP\n\n- **TCP**: Connection-oriented...\n- **UDP**: Connectionless...`
}

Option 2: GitHub Pages Hosting

This site is 100% static with no build steps! To host on GitHub:

  1. Push these files to a GitHub repository.
  2. Go to Settings → Pages.
  3. Under Build and deployment, set Source to Deploy from a branch and select main / (root).
  4. Click Save. Your website will be live in 60 seconds!
